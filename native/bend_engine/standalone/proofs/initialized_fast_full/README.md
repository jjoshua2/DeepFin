`47d4f2aedfc04482b26b94fd55e66864d767542c`, tree
`109014769014128faa62dd543f5490d989ba0c35`.

`Queries` constructs the old rook/bishop whole-pair contracts and each actual
moved-board contract required by the existing generated bypass proof. It composes
the initialized masks, scalar ray-key normalization and actual slider/path
equality. Both contracts return the exact input array. The new occupancy is
`Chess.occupied(Chess.make_move(b,m))` for the exact full Ply. The original
selected king index is bounded by its nonempty plane; singleton kings are not
required. Slider queries ignore side in actual dispatch, so the query adapter
allows any U32 side and arbitrary occupancy. No board validity is required to
establish those lookup contracts.

`consumer.use_legal_full` proves equality of the complete actual
`Chess.legal_moves(a,b)` result and full filtering of the exact actual prefilter
candidate list, including both castle producers, from `(a,Nil{})`. Its premises
are `a==Init.run(d,seed,n,extra)`, depth 17, 128 slider tables, 64 extra squares,
`Board.valid(b)`, a nonempty original-side king plane, and canonical original
turn `get_turn(b)==Bool.to_u32(white)`. Old and child lookup contracts are
constructed internally. The actual initial-check True branch uses the existing
prepare/full flow directly. The False branch constructs its whole-pair initial
certificate and calls the existing generated bypass safety proof. No initial
safety, king uniqueness, EP coherence, target geometry or child validity premise
is added to this legal/full equality.

`consumer.use_list` additionally requires the actual initial check to return
`(a,False)` and one actual full-Ply generated membership certificate for every
supplied occurrence. It relates actual fast and full filtering of arbitrary
ordered lists of generated values, including reordered or repeated promotions,
EP and guarded castle records. Both filters use the same arbitrary retained tail,
which may contain duplicates or unrelated moves and needs no classification.
`Queries.occurrences` constructs a fresh affine lookup callback at every list
occurrence. Neither membership nor callback lists are deduplicated.

The affine input array is consumed once by the existing structural storage
reification. A duplicable exact constructor image supplies all proof queries;
equality transport preserves every original array leaf. The source and consumer
do not normalize a closed initialized array or the zero-argument `Tables.build`.
No native pointer identity or default builder conversion is claimed.

`Fixtures` calls the new public consumer on one symbolic actual generated
full-Ply member repeated twice and an identical arbitrary tail. Separate calls
keep the complete queen-promotion and EP records. These conditional invocations
do not assert that either fixed record is generated by every board or expand a
concrete initialized legal list.

The result removes the prior explicit lookup assumptions for this initialized
table family. It proves implementation filter equivalence under the stated
premises. It does not establish all ordinary or king-move forward safety,
move-generation completeness, reachability, history or full chess legal-move
correctness. Existing qualified providers and their negative controls remain
unchanged.
