## Three public source contracts

| Contract | Guarantee and explicit premises |
| --- | --- |
| `own_block_header` | Every valid key's actual mask/widened prefix is present after one complete actual table iteration, including fill; arbitrary complete depth-17 array. This promotes the previously checked supplementary theorem. |
| `stored_header_after_tables` | The selected key `before+k` has its intended header after the actual loop executes `before+1+after` blocks from key k and certified prefix(k). Requires the complete initial shape and total plus k <=128, not assumed header values. |
| `stored_header_after_extras` | The same complete returned-array/value result after actual allocation and bounded extras. Complete shape is derived, depth is symbolic with equality to17, seed is arbitrary, extras count+start<=64. |

The first contract is promoted, not rediscovered or counted again as a new result
beyond the prior supplementary theorem. The two later-stage contracts are new.
Every returned pair contains the final updated array, not the initial buffer.
The source mask value remains the actual relevant-mask computation. Independent
mask/ray geometry and all final slider-data contents remain distinct obligations.

Addresses proves the two header regions and distinct keys cannot overwrite each
other; it does not enumerate all key pairs. Preserve combines actual writes with
whole-fill outside framing, including arbitrary incoming values. Stored inducts
over the selected position, proves its value survives the suffix, and transports
through the already checked equality to actual Tables.tables. Pipeline composes
with actual extras and supplies allocation shape. The public proof imports all
certificate producers; no desired size, value or frame condition is assumed.

The universal parameter domains include full128-block/64-square instances. The
consumer checks both mask and prefix alternatives and concrete first, boundary,
last and full-count budget certificates. It does not run a separately closed
normalization of `Tables.build()`.
