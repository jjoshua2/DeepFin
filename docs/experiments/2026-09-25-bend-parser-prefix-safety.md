## Contracts and their role in P3

The five universal contracts prove complete Layout concatenation composition,
rejection after any invalid prefix, validity of every prefix of an accepted parse,
metadata preservation, and exact twelve-way typed piece/color character behavior.
All refer to actual Position functions. Metadata and raw cursor values remain
arbitrary. The computed Layout equalities include all Board fields, cursor and
flag; observational laws explicitly state their narrower results.

String induction proves composition and persistent invalidity. A checker-proved
33-case U32 dispatch bridge covers slash and all other characters. Metadata
framing reuses the actual insertion theorem; typed character proofs use the
existing six-piece encoding. No correctness axiom or desired parser result is a
caller premise, and the accepted-prefix premise is demonstrably satisfiable.

This is a foundation for deriving freshness from accepted traversal, **not that
freshness theorem itself**. Rank/file bounds, address injectivity and occupancy
monotonicity must still be connected to the accepted trajectory. A valid prefix
need not itself be a complete accepted layout. Full six-field FEN validity,
partition preservation by the whole parser and reachability remain separate.

The consumer records a non-rollback boundary: `x` can add a black color bit before
validity becomes false; actual layout_result then rejects it. The outer FEN path
does not return that failed Board. No production defect or transactional rollback
of the raw Layout is claimed. Saturating out-of-range U64 bit behavior is retained
rather than incorrectly assumed to mask square numbers modulo64.
