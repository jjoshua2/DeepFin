## Actual E2TB selection path

Resolved generation enables diff-focus, q_weight6, pol_scale3.5, slope3, min_keep.025; normalizer isOFF. In both actual native `_mcts_tree.c:5668–5708` and Python fallback `network_turn.py:955–989`, raw difficulty is6*abs(completed-searchQ−raw-networkQ)+3.5*KL(network prior,MCTS policy), and keep probability isclamp(3*difficulty,.025,1). The value and policy are the network/MCTS/TB-corrected search family, not SF labels. Soft-resign sample_weight (`network_turn.py:582–598`) separately depends on consecutive low raw-network win probabilities, also not SF.

`finalize.py:964–977` uses those two probabilities to drop policy-bearing rows. Its SF/search disagreement is calculated later (`1049–1056`) and attached to the retained ReplaySample as priority_sf_search_gap (`1159`). No stockfish_turn mutation of these keep probabilities/priorities is on the ordinary annotation path; its only literal neutral priority/weight/keep assignments belong to a separate SF-refute-row producer, excluded by actual96 all-NET/non-refute proof scope. Thus the stored SF-gap column cannot retroactively alter this producer thinning.

A separate production replay mechanism CAN use SF labels even with zero SF loss weights: `replay/disk_buffer.py:880–942` computes either stored abs SF–search gap or signed overoptimism, then `_shape_shuffle_priority` adds it only when sf_gap_priority_weight>0. But actual frozen YAML and strict mirror set replay_sf_gap_priority_weight0, and this experiment never uses DiskReplay's prioritized sampling path. The actual paired runner recomputes one NumPy uniform40x256 index matrix (`run_paired.py:425–439`); `paired_observer.py:200–215` slices those exact indices. Stored priority_sf_search_gap is not a determinant of its draw plan.

Therefore there is no source-evidenced SF-numeric selection/thinning/replay-priority influence in this actual experiment through these routes. SF annotations are still materialized for diagnostics/availability and could fail a label-integrity check or consume scheduling/wall time; this is not a counterfactual proof that disabling the SF process would preserve every runtime event/RNG trajectory. The actual source still uses strictTB corrections/search/adjudication/policy rescoring, which are separate from SF annotations.

The retained dataset IS nonuniform: own-MCTS disagreement and network soft resignation select rows before uniform learner draws. Uniform sampling of retained rows does not undo that upstream selection or restore discarded SF-disagreement positions. Zero SF loss weights alone would not imply annotation-blind data in general; here that conclusion additionally depends on actual gap weight0 and the direct uniform sampler. No claim of optimality or causal explanation for the current playing results follows.
