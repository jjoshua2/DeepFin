# Author self-review and limits

This is not an independent review or approval. The public source laws were checked
with the unchanged pinned checker; full dependency bodies were included.

The statement constrains the returned table component, not legal moves or immutable
heap operations. Public callers supply actual arrays, not assumed reifications:
PROOF constructs Representation.reify and Lift transports the checked result.
Scan derives the actual decoder cases without a Board-consistency premise. Filter
covers checked and unchecked paths; Generator uses both castling sides and actual
filter_prepare. Internal pair continuations require and use their preservation
certificates. Native inputs remain narrower than the formal domain.

The regression gate rejects deliberate state loss in each consequential connection.
Policy controls use realpath checks before recursion, so symlinked imports do not
silently pass. Warning-on-zero is a synthetic unit. The separate queen-union to
intersection mutation passes storage checking, delimiting rather than overstating
the result. No inherited source was changed.

The native test checks all logical slot values, including large patterned and
real initialized arrays; it is not pointer/allocator/lifetime proof. Its full-list
comparisons are same-code differential tests, not a chess legality oracle. All
three generic mutation builds leave ordered lists unchanged, but damage stored
state. Reports retain hashes and move traces rather than all bulk slot output.
