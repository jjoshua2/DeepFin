# RL-loop evidence log (rolling index)

- **What this is.** One searchable index of every measurement banked for the RL-loop work since the
2026-11-19 takeover, plus the earlier loop runs it builds on. Each row names its bank file and the
record or PR that carries it. It indexes; it does not re-derive. Numbers are copied from the named file.
- **How to use it.** Grep here before commissioning any match, ruler, throughput run or audit. If a row
answers the question, read its bank file instead of re-running. Check "Registered but not yet read" so
in-flight work is not duplicated.
- **How to add a row.** One row per banked measurement, added in the same PR or session that banks it.
Pick the table by what was measured:
  - **Table 1 (Matches):** any game-playing measurement. Columns: date, question, candidate vs reference, sims, mode / temp / noise, games, openings + seed, Elo [95% CI], status, bank + file, record / PR.
  - **Table 2 (Offline):** rulers, labels, audits, screens and model diagnostics that play no games. Columns: date, what, rows / set, result, status, bank + file, record / PR.
  - **Table 3 (Throughput):** speed, memory and engine-rate measurements. Columns: date, setting, result, GPU state (idle / shared, and with what), bank + file, record / PR.
  - **Table 4 (Facts):** a reusable infrastructure fact that is not itself a measurement. Columns: number, fact, source.
- **Cite the version, not just the path.** Every bank file is cited with its sha256 prefix in square brackets
(`file` [`1a2b3c4d`]) or, for a directory, glob or file still being written, its mtime. Bank files have been
rewritten in place (`ruler_consensus.json` at 02:32 and again 02:48, `ruler_table.json` at 02:33 on 11-21), so a path
alone does not pin a number. In `RC/search-compose/` (read-only since 11-21) cite the frozen `*.v2.json` / `score.v1.json`
copies, never the unversioned names; for the diagnosis's conclusions cite `RC/search-compose/README.md` [`a7443a65`] (addendum 11). Rows marked "same" inherit the row above's citation.
- **When a queued item is read,** move it out of "Registered but not yet read / queued" into "Already
answered" in the same edit, and add its row. When a number is superseded, add a line to the last section.
- **Status vocabulary.** *registered verdict* (pre-committed rule applied) · *diagnostic* (no rule;
decides nothing) · *screen* (selection instrument; needs confirmation) · *control* (a check that the
instrument does what it claims: identity, mutant, take-effect) · *rehearsal* (a dry run of a procedure;
not a measurement) · *interim* (bank still being written) · *in progress* · *not run* · *withdrawn*
(claim retracted; see the last section) · *discarded* (bank exists but must not be used: corrupted,
interrupted or superseded).

The bank's own pointer file is `RC/INDEX.md` (one line per bank directory).

Abbreviations: `RC` = `~/chess-artifacts/operations/rl-claude-20261119`, `WK` =
