## Contracts and argument

| Contract | Actual source guarantee |
| --- | --- |
| `later_tables_preserve_data` | The entire actual remaining table-loop call preserves an earlier bounded data query and returns the complete updated array. |
| `stored_data_after_tables` | Every valid interior entry of a selected block has its computed slider value after subsequent metadata and other-block writes. |
| `stored_data_after_extras` | The same computed entry survives the actual final extras loop after actual allocation and table-building. |

The arbitrary-array statements require complete depth-17 shape. A protected
prior query satisfies `512 <= q < prefix(start_key)` and `q < 131072`. For a
selected block, `before + 1 + after + start_key <= 128` and the relative Nat index
is strictly below the actual mask-derived size. Allocation supplies the shape
certificate in the final pipeline statement. Extras require their square budget
at most 64; the initial seed stays arbitrary.

The proof derives exact encoding and actual U32 address bounds for every bounded
Nat interior index; it does not assume a conversion result or a expected value.
Later metadata slots are below 256, while every protected data slot is at least
512. Existing complete-tree frame laws protect those slots, and the earlier
outside-fill law protects them through every later block. Induction over the
actual prefix schedule then composes with the previously proved actual-loop
equality. The computed-entry proof starts after both actual header writes, uses
the completed fill-value theorem, and composes with the final extras law.

The consumer retains symbolic arrays/depth to avoid normalizing a huge literal
allocation. It includes full128-block and full64-square budget witnesses, first
and last interior indices, a positive later-block frame domain and exclusion of
the block's exclusive end. These demonstrate satisfiable parameter domains, not
a separately normalized closed Tables.build theorem.
