# Ceres fixed32 source timing observation

**CPU-only source readout, September 30, 2026.** The recovered fixed32 Ceres producer remains on its reviewed run-8 packet. Across closed chunks 7–22, its saved progress receipts cover 2,070,718 attempted roots and 66,992 physical-32 calls in 11,480.483 seconds of actor wall. Root preparation and outcome handling, including nested sink publication, occupied 5,812.464 seconds (50.63%); the sink accounted for 2,522.258 seconds within that time. Inference preparation plus the bound ONNX call occupied 5,407.243 seconds (47.10%). Choice and move application occupied 198.235 seconds (1.73%), leaving 62.541 seconds (0.54%) unassigned. The sink is already included in root/outcome time, so adding those two figures would double-count it.

These saved progress fields do not separate CPU encoding/gather from `session.run`, and host `session.run` time is not GPU kernel time. Source and strict CPU readback overlap. An independent check of original completion-file timestamps over chunks 7–14 measured 172.809 unique accepted feed inputs per second for that window; this is fixed32 source-only cadence, not integrated teacher, corpus, training or long-horizon throughput. A separately reviewed independent replay of the first closed run-8 ZIP shard passed all 8,152 accepted and attempted rows, including 37 natural and 31 Syzygy game endings. It remains one-shard, zero-admission evidence; full completed-game raw GPU policy vectors were not banked for same-call replay.

The actor already computes a `ScheduleReceipt` with root/outcome excluding sink, CPU inference preparation, bound `session.run` host wall, choice/application, and sink including final publication. The fresh child currently omits those components from its durable receipt. The [one-file observation patch](evidence/2026-09-30-ceres-source-phase-observation.patch) persists them under `phase_seconds` and refuses nonfinite, negative, inconsistent-wall or greater-than-5%-residual receipts. The five components are disjoint by the existing actor accounting; this patch does not change scheduling, the model, teacher calls, targets, or ZIP publication.

The [CPU fixture](evidence/2026-09-30-ceres-source-phase-observation-test.py) passed one valid five-component receipt and four corruptions. The patch applied exactly to an isolated copy of the reviewed fresh-child source, producing the pinned candidate SHA-256. The [evidence record](evidence/2026-09-30-ceres-source-phase-observation.json) pins the source delta, fixture, readouts, independent archive receipt and reproducibility check. This is a proposal for a separately sealed successor packet; run 8 and its GPU process were not modified. The 5% residual is an accounting gate, not a measured speedup.
