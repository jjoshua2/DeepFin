## Three new contract statements

| Law | Actual implementation guarantee and explicit preconditions |
| --- | --- |
| `bounded_fill_entry` | For arbitrary complete depth-17 initial storage, arbitrary slider parameters/start subset, `i < n`, and `n + nat(at) <= nat(end)`, `end < 131072`, actual get-after-full-fill at actual U32 `at + from_nat(i)` returns the slider value for iteration i. |
| `bounded_zero_fill_read` | With zero-start fill, the selected state is the existing accepted `Sequence.at(i,mask)`. The complete returned pair contains the actual final updated array, not the initial array. |
| `full_block_entry` | Every valid chess block and every selected relative index returns that computed entry and the complete final block array. Actual count/end facts are produced by the existing prefix proofs, not assumed by the caller. |

The mathematical value connection is internal to the actual fill computation:
`Tables.slider` is still the value specification. Independent blocker-ray equality
is not claimed source-proved by these contracts. Nor do they prove persistence
through the complete builder's later headers, other blocks or extras, or equality
of loaded metadata to certified prefixes. Those remain P2 obligations.

Proof structure: preserve the first write through its suffix using inherited
interval framing, induct over arbitrary selected positions and exact Nat count
splits, prove the modular repeated-increment/U32-add correspondence, connect the
zero-start traversal to the old recurrence, and transfer through the certified
actual affine-array representation. The public full-block proof constructs its
budget from accepted prefix/size facts. No caller assumes the desired read value.
