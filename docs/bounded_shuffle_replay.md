Order and quota

The new order identity is APPROXIMATE_BOUNDED_SHUFFLE_V1. Fill a fixed number of slots from the sequential upstream, choose a uniform random slot, emit it, replace it with the next upstream row, then drain at EOF. This bounded-window process is not a globally uniform permutation. Producer timing, decoded NNZ, optional flags and actual byte occupancy never decide selection: slot count is fixed and all rows reserve the same global header-derived maximum row charge. Too-small caps refuse before the first source decode/draw; the engine never skips a row or shrinks the configured buffer to fit. No priority or natural-board deduplication occurs. Every original generation/source-SHA/local-row identity is emitted exactly once, including the true final partial batch.

The independent private random.Random selection state never consumes source.rng, which is the original PCG64 augmentation RNG used by Trainer for mirroring. Both states are checkpointed and restored without another draw. Ready rows may advance the selection/source frontier but are NOT presentations. Only sample_batch_arrays reserves original physical identities in the durable callback BEFORE returning payload to mirror/forward. Original and mirror share one reservation. A reservation/source/assembly/forward failure taints; no clean checkpoint or redraw follows. The unchanged QuotaLedger can reserve these new encoded records and enforce lock/fsync/parent-tail equality, but old global-permutation journal/closed-model validators MUST NOT accept this family.

Memory and source ownership

ReplayLimits has explicit source, buffer, ready, consumer and scratch byte caps whose sum cannot exceed the selected replay total. It also fixes row capacity and at most four ready batches. There are no active/default caps. An INERT engineering example for a1GiB replay target is source460MiB, buffer256MiB, ready16MiB, consumer256MiB, scratch36MiB, with2048slots/B32/two ready batches; the constructor must still reject it if the actual declared maximum source/row/assembler budgets do not fit. This example is not selected scientific/runtime authority.

The source factory retains reviewed immutable inventory/seal/codec/validate=True/history/target/TRAIN checks. It precomputes named header-derived budgets before decoding and caches at most one source. The old cache is dropped BEFORE successor decode. Each returned row is an owning writable copy, with32KiB per-row array-object headroom and a128-field guard; views cannot pin an entire shard. Buffer/ready copies acquire byte credit BEFORE allocation. Consumer assembly acquires a conservative declared temporary/output reservation before real ArrayReplayBuffer conversion/gather and detaches all output arrays, including scalar markers. Actual owning ndarray base allocations are charged, not just a small view's nbytes. A few ready batches exert backpressure. A single producer prevents multiplying source-decode workspaces. Existing pre/post raw inventory hashes still read source bytes; one sequential decode does not mean a single physical disk-byte read.

This target covers replay ndarray/owned-row and declared source/assembly workspaces plus scratch. It does not bound full process RSS. Torch/framework/model/optimizer/GPU tensors, the parsed124MB manifest and frozen metadata/Python graphs, allocator retention and OS page cache are separate. No compact metadata parser or whole-RSS1GB promise is introduced.

Checkpoint frontier

Checkpoint first signals and joins the producer without holding its condition during join. Any active producer batch finishes as an ordered ready batch; there is no hidden producer frontier. Caller must finish/release a borrowed consumer batch before checkpoint. State carries source-prefix cursor, ordered slot IDs, FIFO ready batch IDs, emitted bitmap/counts, reservation chain, identity/origin-map binding and separate shuffle/mirror RNG states. Prefix input rows partition into spent IDs, slots and ready rows; all later rows are untouched. Ready batches do not spend quota. Decoded source payload is discarded at the barrier. Restore validates shape/partition/config/RNG/journal frontier before source I/O, then reconstructs payload from exact IDs without RNG selection or re-reservation. Restore may reopen already checked source shards; an uninterrupted pass decodes each sequential shard once. Actual source reads need the normal finite owned-process deadline: a Python worker cannot safely preempt a kernel-blocked decoder. A successful checkpoint/close joins its producer; an I/O fault remains a tainted owned failure and is not permission to continue.

Metadata-only lineage verification is concrete: audit_selection takes authenticated parsed canonical reservation records and the closed state, replays symbolic IDs with the same fixed slot algorithm/seed, checks emitted physical IDs and rolling chain, reconstructs the unspent ready order, and compares slots/source cursor/private RNG/spent bitmap. It reads no payload and assumes no NNZ. Caller must authenticate immutable raw checkpoint/journal bytes and strictly parse bounded records first; checksum and audit output are not model, actual-forward or launch authority.
